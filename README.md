# Creature Search App
A small RPG-style creature lookup tool. Enter a valid creature name or ID from the API and get rich details like types, stats, weight, and height in real time.

## Examples you can try:
- Pyrolynx  
- Aquoroc  
- Voltadon  
- Floraspine  
- Titanule

## Features
- Searches by name or numeric ID.
- Retrieves creature data using the freeCodeCamp RPG Creature API.
- Displays types, stats (HP, attack, defense, etc.), weight, and height.
- Responsive design and clear, JS-driven interface.
